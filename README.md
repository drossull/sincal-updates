# SINCAL Updates

Canal público de distribución de **SINCAL Suite 1.0**.

Este repositorio contiene únicamente recursos que la aplicación instalada puede actualizar sin reemplazar el ejecutable:

- rutinas AutoLISP;
- archivos de inicio CAD;
- scripts PowerShell, BAT y SCR;
- estilos de ploteo;
- mapas y configuración de tutoriales;
- el master `FORMATOS ANOTATIVOS ACAD_2025.dwg`.

El código fuente de la aplicación y del plugin se mantiene en un repositorio privado. El contenido de este repositorio se genera mediante una lista blanca; `manifest.json` publica el tamaño y SHA-256 de cada recurso para facilitar auditorías.

Los instaladores oficiales se publican en la sección **Releases** y están firmados con Authenticode.
